# Веб-доработки и общая архитектура

Локальная ветка: `codex/web-integration-per-diem`. Исходная настольная версия: 3.5.23 с новым слоем приложения и оптимизацией графиков/сохранения. Веб-изменения перенесены из снимка 121 изменённого или нового исходного файла; оригинальная папка веб-разработки не изменялась.

В общую ветку включены многостраничный веб-интерфейс, локальный сервер, учётные записи и права, серверная очередь и восстановление операций, документы и PDF, развёртывание, импорт реестров, распределение счетов по авто/ДЭС/водителям, контрагенты, финансовая статистика и сравнение бюджета. Настольные реестры и финансы используют те же экраны и расчёты через адаптер; прежние ручные финансовые записи доступны из вкладки учёта.

Сохранены новые настольные контроллеры и проверки подтверждения записи. Старый веб-мастер настройки ТО не заменяет новый типизированный контроллер: нужные функции объединены через общие порты. Ускорение больших графиков и точные исходные значения сохранены.

Суточные: [инструкция](driver-per-diem.md). Данные поездок хранятся отдельным полем `drivers.perDiem` версии 1. Миграция схемы не нужна; суммы не записываются автоматически в выплаты или расходы. Ставка и правила оплаты задаются явно для каждой поездки.

Проверки выполняются только на синтетических данных и в отдельных временных папках. Рабочая база, настройки установленной программы и установленный веб-сервер не меняются. Полный прогон, сборка установщика, публикация и отправка на GitHub не выполнялись.
