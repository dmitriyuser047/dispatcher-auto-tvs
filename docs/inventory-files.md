# Файлы инвентаризации

В разделе «Инвентаризация ОС» кнопка «Загрузить файлы / архив» принимает отдельные файлы и несколько выбранных файлов любого формата. RAR и ZIP сохраняются целиком и распаковываются: документы внутри остаются отдельными оригиналами с исходными именами, путями и контрольными суммами. Повторная загрузка одинакового файла по тому же пути не создаёт копию. За одну загрузку допускается до 25 МБ исходных файлов.

Приказы, акты, PDF и сканы сохраняются как документы. Загрузка оригинала сама по себе не меняет количество имущества и не создаёт утверждённую опись. Оригинал можно сохранить в выбранную папку через кнопку «Сохранить файл».

Для Excel и прежней базы JSON доступна кнопка «Разобрать опись». Автоматический разбор поддерживает ОСВ, табличные сличительные ведомости и многостраничные печатные формы ИНВ-19 с обложкой и продолжениями. Перед записью показываются состав, объекты, даты, предупреждения и предварительный результат. Нужно указать основание и подтвердить импорт. Если документ не содержит нужных реквизитов, они уточняются в форме; оригинал при этом остаётся в разделе.

Разбор учитывает содержимое документа, включая даты «по состоянию», организацию и заголовки разделов. Имя файла не заменяет эти реквизиты. Расхождения между именем, титульным листом и внутренними заголовками показываются предупреждениями. В прежних формах с разными колонками учётная стоимость и фактические значения не смешиваются; отсутствующие значения остаются неизвестными. Все исходные строки сохраняются, включая исторические ведомости; проверка повторяющихся позиций между разными документами остаётся частью просмотра перед импортом.

Оригиналы находятся в собственной базе инвентаризации и включаются в её резервные ZIP-копии. Основная база транспорта и ДЭС не изменяется. При сетевой работе сервер и рабочие места должны использовать версию с поддержкой этой загрузки.
