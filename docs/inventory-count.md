# Подсчёт имущества

В строке описи галочка «Совпадает» подставляет учётное количество и учётную сумму в фактические значения. Поле количества при этом доступно для чтения. Если снять галочку, поле очистится и можно будет ввести фактическое количество вручную.

Цена за единицу берётся из зафиксированных в описи учётной суммы и количества и не редактируется при подсчёте. Фактическая сумма рассчитывается по этой цене автоматически. Расчёт использует полную точность отношения; до копеек округляется только конечная сумма. Введённый ноль сохраняется как ноль, пустое количество означает неизвестный факт.

Если учётного количества или стоимости недостаточно для определения цены, сумма остаётся неизвестной. Учётные реквизиты можно уточнить отдельным действием «Исправить учётные данные». Ранее сохранённые фактические суммы остаются прежними, пока пользователь явно не изменит количество или галочку в этой строке. Утверждённые описи сохраняют зафиксированные значения.

Колонка «Фото позиции» позволяет добавить к строке одну или несколько фотографий JPEG, PNG, WebP или GIF. Они сохраняются сразу, отдельно от ещё не сохранённых количеств. Во время загрузки нужно дождаться сообщения «Фото сохранено». Для повторения неудавшейся загрузки доступна кнопка «Повторить загрузку».

Фотографии можно посмотреть по миниатюре, повторно открыть вместе с описью и восстановить из резервной копии базы. После утверждения существующие фото остаются доступны для просмотра; добавление новых выполняется в черновике. Фото относится к конкретной описи и строке. Оригиналы, имена файлов и привязки сохраняются без изменения основной базы транспорта и ДЭС.
