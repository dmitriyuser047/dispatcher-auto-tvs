# Проверка ГСМ и исправление источников

Откройте **ГСМ → Проверить ГСМ**, выберите месяц и организацию. Проверка читает данные без сохранения. Поиск находит машину, дату, организацию или причину. Замечания разделены на ошибки полей и связей, случаи для сверки документов и предупреждения.

У отрицательного остатка раскройте историю. Первая дата причины может находиться раньше выбранного месяца: повторный перенос минуса не является новым поступлением или расходом. Кнопка источника открывает соответствующую покупку, запись журнала, карточку машины или историю карты. После ручного сохранения проверка пересчитывается.

| Замечание | Где проверить и исправить |
| --- | --- |
| Литры выписки отличаются от журнала | Откройте покупки и запись журнала из замечания. Сверьте все операции дня с выпиской; не добавляйте приход второй раз. |
| Возможный повтор восстановления | Сопоставьте все покупки группы с исходником. Совпадение признаков не доказывает дубль. Подтверждённую лишнюю строку удаляйте из выписки с выбором, нужно ли снимать литры журнала. Для сохранения правильного журнала выберите соответствующий режим, проверьте предпросмотр и укажите причину. |
| Неверная историческая организация | В покупке включите отдельное уточнение организации и укажите основание. Обычная правка текущей карты сохраняет историческую организацию прежних покупок. |
| Покупка не связана с журналом | Проверьте фактическую машину, дату и марку. Такая покупка уже входит в приход расчёта. Исправление подтверждённой покупки пересчитает её связь с журналом. |
| Повреждённая марка или число | Откройте исходную покупку или запись журнала и исправьте поле по первичному документу. |
| Запись журнала потеряла связь с машиной | Выберите подтверждённую существующую карточку, укажите основание и проверьте предпросмотр. Изменится только ссылка записи на ТС; связанные покупки требуют отдельной проверки. |
| Замер выше расчёта | Проверьте предшествующие поступления и расход, затем источник замера. Разница выводится как корректировка, а не как подтверждённое поступление. |
| Нет замера на конец месяца | Остаток расчётный. Если существует реальный замер, внесите его на соответствующую дату. Само отсутствие замера не доказывает ошибку. |
| Начальные источники не равны карточке | Проверьте общий исходный остаток карточки и его распределение по организациям и топливу. Это исходный остаток за всё время учёта, а не способ задать конец отдельного месяца. |
| Месячная сверка отличается от операций | Проверьте контрольное месячное значение и первичные операции. Акт строится по операциям. |

Закрытый месяц нужно открыть штатной командой закрытия периодов с указанием причины. Проверка не обходит эту защиту.

Акт доступен через **ГСМ → Списание → Выгрузить акт** и прежнюю кнопку «Акт ГСМ» в транспорте. Литры выводятся до 0,001 л; холостой ход уже включён в «К списанию». Основания расчёта по норме и замеру раскрываются отдельно. При отсутствии нормы экономия и перерасход не вычисляются.

Если есть ошибки источников, программа предлагает проверить их либо выгрузить явно помеченный черновик с расхождениями. Корректировки раскрываются в приложениях, чтобы выполнялось равенство: начало + поступления + корректировка − списание = конец. Исходные отрицательные остатки не скрываются и автоматически не исправляются.
