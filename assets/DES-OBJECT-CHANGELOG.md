# ДЭС объекта 0.1.2

Выбранные в центре ёмкости принимаются с расчётным остатком, датой и основанием передачи. Новая выдача через журнал уменьшает этот остаток; обычный приход проводится отдельным документом. Входящие топливо и счётчик ДЭС сохраняются при обновлении данных. Старые исторические операции остаются в центре, исходные значения рабочего учёта не переписываются.

# ДЭС объекта 0.1.1

Исправлена начальная привязка и выдача карточек ДЭС, связанных с общей ёмкостью центра. Перед загрузкой видны предупреждения об исключённых связях. Сохранение подключения сохраняет выбранный HTTP/HTTPS; организация и объект редактируются до первой загрузки данных. Окно имеет отдельный заголовок «ДЭС объекта».

# ДЭС объекта 0.1.0

Отдельная программа для одного объекта со своей SQLite. Карточки ДЭС, журнал, ТО, ЗИП, ремонты и операторы используют общее ядро Диспетчера.

Обмен с центром доступен через подписанные файлы и сервер. Перед приёмом изменений центр показывает проверку; квитанция подтверждает принятые операции. Повторная передача не создаёт дубли. Конфликты требуют решения пользователя.

Общие утверждённые графики доступны как объектная проекция для просмотра. Утверждение, закрытие периодов и защищённые исправления выполняются в центре. Оригиналы вложений пока не передаются. Автоматическое обновление этого приложения пока отключено.
