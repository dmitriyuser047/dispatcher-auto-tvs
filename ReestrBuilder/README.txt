РЕЕСТР-БИЛДЕР — автосборка реестра на оплату из архива со счетами

УСТАНОВЛЕНО КАК ОБЫЧНАЯ ПРОГРАММА
  Ярлык "Реестр-Билдер" есть на рабочем столе и в меню Пуск.
  Открывается отдельным окном, браузер не нужен.

  1. Открыть "Реестр-Билдер"
  2. Перетащить zip-архив со счетами в окно (или нажать и выбрать файл)
  3. Нажать "Собрать реестр"
  4. Дождаться лога (✓ зелёным — распознано, ! жёлтым — не распозналось)
  5. Нажать "Скачать реестр.xlsx" — откроется системный диалог "Сохранить как",
     после сохранения папка с файлом откроется сама

  Удалить программу можно как обычную — через "Параметры > Приложения"
  или файлом "Uninstall Реестр-Билдер.exe" в папке установки.

ЧТО ДЕЛАЕТ
  Берёт zip-архив, в котором лежат под-архивы (rar/zip) со счетами
  (в каждом — "Счет на оплату" и/или УПД в PDF), автоматически:
   - распаковывает всё,
   - читает текст PDF (в т.ч. кириллицу — через pdfjs-dist,
     обычный pdftotext/poppler эти PDF не читает из-за особенностей шрифта),
   - вытаскивает номер и дату счёта, сумму, наименование услуги, номер УПД,
   - пытается определить Объект / Доходный договор / Статью БДДС
     по ключевым словам (см. config.json),
   - собирает готовый реестр в Excel (формулы, перенос строк, границы —
     как в образце "Реестр №81").

НАСТРОЙКА ОБЪЕКТОВ/ДОГОВОРОВ (config.json)
  В самом окне программы внизу есть ссылка "открыть" рядом с config.json —
  нажмите, откроется в блокноте. Формат:
    {"keywords": ["слово1","слово2"], "object": "...", "contract": "..."}
  Ищет эти слова и в тексте счёта, и в названии архива (т.к. часто
  объект указан только в названии папки/архива, не в самом счёте).
  Дописывайте свои строки прямо в блокноте, сохраните файл — изменения
  подхватятся при следующей сборке. Программировать не нужно.

  (Для программы, установленной через .exe, файл фактически лежит в
  C:\Users\Admin\AppData\Roaming\reestr-builder\config.json —
  но проще всего просто нажимать "открыть" в самой программе.)

ОГРАНИЧЕНИЯ
  - Если объект по ключевым словам не находится — поле остаётся пустым
    (специально, чтобы не писать туда угадайку).
  - Скрипт ищет файл со словом "счет" в названии как основной документ;
    если такого нет — использует УПД (тоже официальное основание для оплаты).
  - Работает с zip и rar под-архивами. Пароли на архивах не поддерживаются.

ДЛЯ РАЗРАБОТКИ / ПЕРЕСБОРКИ (эта папка — исходники)
  cd C:\Users\Admin\Documents\ReestrBuilder
  npm start              — запустить окно из исходников (без переустановки)
  npm run build           — пересобрать установщик .exe (папка dist\)
  node build-reestr.mjs "архив.zip" "результат.xlsx"   — консольная версия
  node server.mjs         — браузерная версия (на случай, если понадобится)

  После правок в lib.mjs/public/index.html — npm run build и переустановить
  через новый dist\ReestrBuilder-Setup-*.exe, чтобы изменения попали
  в установленную программу.
