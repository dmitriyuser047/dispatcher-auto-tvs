# Диспетчеризация авто ТВС · 3.5.8

Приложение Windows для диспетчеризации автопарка, дизельных генераторов, ГСМ, обслуживания, ремонтов, документов и финансов ООО «Технрайз Велл Сервис».

Версия 3.5.8: отдельный раздел «Инвентаризация ОС» на SQLite. Собственные организации, объекты, МОЛ и имущество; подсчёт факта, утверждение комиссией, история исправлений и новые редакции. Импорт прежней базы и Excel выполняется через предварительную проверку; описи выгружаются в PDF и Excel. Раздел не связан с транспортом, ДЭС или складом запчастей.

[Работа с запасами, графиком ТО и печатью](docs/generator-maintenance.md). [Проверка и исправление данных ГСМ](docs/gsm-corrections.md).

## Установка и обновление

Скачайте **Dispatcher-Setup-3.5.8.exe** из [релиза 3.5.8](https://github.com/dmitriyuser047/dispatcher-auto-tvs/releases/tag/v3.5.8) и запустите установщик. Обновление использует прежнюю идентичность приложения, каталог установки и профиль. Настройки находятся в %APPDATA%/dispetcherizaciya-avto, исходная папка базы — Документы/ДиспетчеризацияАвто_ТВС; выбранная ранее папка сохраняется.

Перед обновлением сохраните резервный пакет в настройках. Пользовательская база не входит в установщик. Для баз схем 1–5 программа предлагает проверенную копию SQLite в формате 6 через «Состояние программы → Копии и перенос базы». Укажите отдельный пустой каталог, дождитесь проверки и явно выберите созданную копию; исходная база сохраняется и доступна для чтения. Нерешённый журнал сохранения прежней версии восстанавливается прежней программой до копирования.

**При общей сетевой базе обновите сервер и все клиентские рабочие места до одной версии.** Проверка базы и прав не позволяет старому клиенту перезаписывать новую схему. Персональные учётные записи и HTTPS настраиваются в программе; существующий общий сетевой ключ сохраняется до настройки персонального доступа.

Обновления читаются из main/version.json. Новый клиент проверяет HTTPS-адрес выпуска и SHA-256 установщика перед запуском. Публикация релиза и переключение канала — отдельные действия; локальная сборка их не выполняет.

## Возможности

- Диспетчерская: заявки, доска и лента дня, назначения техники и сотрудников, контроль занятости и допусков.
- Транспорт и ДЭС: журналы пробега/наработки, история, регламенты обслуживания, ремонты и документы со сроками.
- ГСМ: ведомость по машинам с формулой и источниками, подготовка актов по пяти шагам, отдельные физические ёмкости, поступления и выдачи, карты, редактируемая выписка, ГЛОНАСС-импорт, сверка, закрытие периодов и отчёты.
- Водители и операторы ДЭС: отдельные справочники, назначения, допуски и история работы.
- [Загрузка и табели водителей и машинистов ДЭС](docs/personnel-timesheets.md): импорт Excel с выбором листа, редактирование по дням, проверка исходных итогов, сохранение периодов и выгрузка в формате образца.
- Рабочие процессы: задачи, ремонтные заказы, сменные формы, документы с вложениями, запчасти и шины, склад и история изменений.
- Инвентаризация ОС: собственный реестр имущества, фильтры по организации, объекту и МОЛ, описи с фактическим количеством и стоимостью, комиссия, утверждение и отдельные редакции. Пустое значение означает неизвестное; фактический ноль сохраняется. Утверждённая опись хранит снимок реквизитов и всех строк, даже после изменения справочников.
- Финансы: оплаты, задолженность, бюджет, контрагенты; учтённые расходы на километр и моточас, выручка и отдельные сценарии по ставкам.
- Закупки: потребность топлива и запчастей, резерв, срок поставки, частичные поставки, оприходование и разрывы между поставками. Отметка получения заказа не создаёт приход в журнале автоматически.
- Напоминания Windows: включаются отдельно для базы и пользователя, поддерживают тихие часы и отсрочку; работают, пока приложение открыто или свёрнуто.
- Реестр счетов и PDF-студия: локальное OCR, текст и таблицы, правки страниц, сравнение, проекты и экспорт. Полная точность OCR на рабочих документах требует сверки с оригиналом.
- Постоянная навигация, светлая и тёмная темы, поиск Ctrl+K, резервные пакеты с проверкой контрольных сумм.

Расчёт расходов отражает известные документы, а не полную бухгалтерскую себестоимость. Неизвестные суммы не подменяются нулями; прогноз закупок и расчёты по ставкам показываются отдельно от факта.

## Инвентаризация ОС

Раздел расположен в меню «Документы и расчёты». Сначала создайте собственные организации, объекты, МОЛ со счетами и имущество либо используйте «Импорт прежней базы» для выбранного `data.json` из отдельной программы инвентаризации. Файл исходной базы не изменяется. Для Excel выберите явный формат: ОСВ или опись; укажите дату и недостающие реквизиты, затем проверьте результат и подтвердите импорт. Нераспознанные или неоднозначные данные требуют исправления источника, пустые значения не считаются нулём.

Во вкладке «Подсчёты» создайте опись по объекту, внесите фактические количества и суммы. При необходимости исправьте учётные реквизиты через отдельное действие с основанием. Для утверждения заполните комиссию, фактическую дату и решение. Утверждённая опись сохраняется; «Новая редакция» создаёт отдельный черновик. Кнопки «Сохранить Excel» и «Сохранить PDF» выгружают выбранный документ, включая строки всех его организаций, итоги и комиссию. Подписи проставляются на бумажном экземпляре.

## Документы и OCR

Используется собственная сборка Tesseract 5.3.0-tvs1 на базе закреплённых исходников tesseract.js-core 7.0.0, включая LSTM/SIMD/relaxed SIMD и проверку manifest. Русские и английские модели входят в сборку; исходники, патчи, лицензии и рецепты находятся в vendor/tesseract-core и scripts/ocr-native. Новые нейросетевые веса не обучались.

PDF с исключёнными страницами пересоздаётся из видимых страниц с обработкой до 300 dpi, чтобы удалить скрытые исходные объекты. Программа сообщает об изменении векторной страницы. Проект .tvspdf содержит исходники для продолжения работы; для передачи результата экспортируйте PDF. Редактирование нарушает действительность прежних электронных подписей.

## Разработка и сборка

Выделено [расчётное ядро](docs/engine.md): ГСМ, журнальные остатки, затраты и закупки доступны через общий API в браузере и Node.js. Проверка ядра — `npm run test:engine`, отдельная демонстрация без рабочей базы — `npm run engine:demo`.

Требуются Windows x64 и Node.js 22 или новее.

```powershell
npm ci
npm test
npm run test:ui
npm run test:electron
npm run build
```

Браузерные проверки используют Playwright и установленный Edge либо Chromium. Путь к отдельным библиотекам тестирования задаётся TVS_PLAYWRIGHT_MODULES; проверки используют только синтетические данные и временные профили.

Сборка требует чистый коммит, материализует полный граф производственных зависимостей, собирает Electron, проверяет все файлы ASAR и распакованные ресурсы, затем создаёт dist/release-manifest.json и SHA256SUMS.txt. Итог — dist/Dispatcher-Setup-3.5.8.exe. Рабочие базы и настройки пользователей не включаются.

Release workflow запускается вручную и не перезаписывает существующие выпуски. [Список изменений](assets/CHANGELOG.md).
